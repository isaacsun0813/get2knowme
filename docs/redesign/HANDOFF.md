## The product frame

Rebuild of Isaac's personal site in the existing repo github.com/isaacsun0813/get2knowme: Next.js 15, React 19, TypeScript, three.js with @react-three/fiber and drei, framer-motion 12, Tailwind 4, zustand. The live site and main branch stay untouched until Isaac approves designs.

The site is "Isaac's World": a flyable globe with landmark scenes, and pages that read like pages from his personal magazine. Every page shares one thread (same lettering and stroke language, same physical-paper behavior) but each has its own mood. The standing design rules he asked every page to follow: Rules for Isaac's World.

The game and the globe stay. The bar is "not vibe coded": nothing templatey, nothing that looks generated by default settings.

## Motion and drawing stack
framer-motion 12 (already in the repo) for physics-based UI motion; everything settles - no infinite loops.
Motion Primitives (https://motion-primitives.com/) as a reference/source for DOM-level animated components: scroll reveals for timeline knots and letter tags, staggered groups. It does not provide 3D board or cord physics.
Custom three.js/r3f work for the board and globe: grabbable objects, cord constraints, page bending - built by hand or with a 3D physics library, not from UI component catalogs.
perfect-freehand for hand-drawn strokes (optionally Rough.js; Rough Notation for draw-on underlines). React Rough Fiber was evaluated and dropped as too immature.
Watermelon UI (https://ui.watermelon.sh/) and Haikei (https://haikei.app/) were evaluated and set aside: ready-made blocks and stock SVG backgrounds pull toward the template look he rejects.
